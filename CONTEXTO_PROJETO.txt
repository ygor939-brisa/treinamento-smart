PROJETO: TREINAMENTO SMART
Data deste pacote: 22/10/2026

1. OBJETIVO

Portal interno de treinamento para operadores da Smart Risk. O site reúne:
- manuais resumidos de teclados e tecnologias de rastreamento;
- procedimentos de desbloqueio sem sinal separados por tecnologia;
- demonstrações visuais com o equipamento real e uma mão semitransparente indicando onde tocar;
- um assistente local chamado Analista Smart;
- uma Área ADM de protótipo para cadastrar novas respostas no navegador.

O site é totalmente estático: HTML, CSS e JavaScript, sem framework e sem etapa de compilação.

2. COMO EXECUTAR

Opção simples:
- abra dist/index.html no navegador.

Opção recomendada para desenvolvimento:
- abra um terminal na pasta do projeto;
- execute: python -m http.server 4173
- acesse: http://127.0.0.1:4173

Para publicar em hospedagem estática, envie o conteúdo da pasta dist.

3. ESTRUTURA PRINCIPAL

- index.html: estrutura de todas as páginas e símbolos SVG usados como ícones.
- styles.css: design completo, responsividade e animações.
- app.js: dados dos manuais, fluxos, animações, navegação, chat e Área ADM.
- assets/: logo, robô e imagens dos equipamentos.
- dist/: cópia pronta para hospedagem.
- .openai/hosting.json: configuração do projeto originalmente publicado com OpenAI Sites.

4. DECISÕES DE DESIGN

O primeiro conceito estava visualmente genérico e usava muitos cantos arredondados, cores fortes, círculos decorativos e símbolos semelhantes a emojis. A revisão atual mudou isso:
- visual corporativo em azul-marinho, branco e cinza;
- azul vivo usado apenas para ações e estados ativos;
- cantos com raio pequeno;
- remoção de órbitas, bolinhas e enfeites sem função;
- ícones SVG consistentes desenhados no próprio HTML;
- menu com todas as opções alinhadas na mesma altura e proporção;
- cards retangulares e com hierarquia mais técnica;
- equipamentos reais nas animações.

5. ANIMAÇÕES DOS TECLADOS

As demonstrações usam imagens reais extraídas dos manuais ou fornecidas pelo usuário. A mão é um SVG semitransparente criado no HTML/CSS e se move por coordenadas percentuais.

No app.js:
- manuals[].flow contém título, texto, posição X e posição Y de cada toque;
- technologies[].points contém as posições da mão para o desbloqueio;
- moveHand() aplica as coordenadas e reinicia a animação de toque;
- demoSequences controla a demonstração automática da página inicial.

Equipamentos com imagem confirmada neste pacote:
- Smart TAB / SIGHRA;
- OnixSmart / OnixSat;
- Terminal Alfanumérico Omnilink;
- teclado do Guia do Motorista;
- SasMDT Sascar;
- Autotrac.

RAVEX, HÍBRIDO e POSITRON usam deliberadamente um terminal esquemático com o aviso “Interface ilustrativa — confirme o modelo instalado”. Isso evita associar uma foto incorreta a uma tecnologia. Quando houver imagens oficiais desses equipamentos, basta adicioná-las a assets/devices e preencher a propriedade image no respectivo item de technologies em app.js.

7. ANALISTA SMART

O Analista Smart atual é um protótipo local, não uma integração real com IA:
- builtInKnowledge, em app.js, contém respostas fixas;
- o sistema procura palavras-chave na pergunta;
- conteúdos cadastrados na Área ADM são gravados em localStorage;
- os dados existem apenas naquele navegador e computador.

Para uma versão corporativa, será necessário substituir essa lógica por:
- backend autenticado;
- banco de dados central;
- controle de permissões;
- recuperação de conteúdo dos manuais;
- integração com um modelo de IA.

8. ÁREA ADM

A Área ADM é somente um protótipo de interface:
- o primeiro acesso cria e guarda localmente o e-mail e um hash da senha;
- a sessão usa sessionStorage;
- as novas orientações usam localStorage;
- não deve ser considerada autenticação segura para produção.

9. SEGURANÇA DO CONTEÚDO

O portal não exibe contrassenhas, senhas operacionais ou códigos reais de desbloqueio. Os fluxos descrevem somente o processo, a validação e os pontos de interação. A orientação visual deve continuar respeitando essa regra.

10. ESTADO DO PROJETO

O pacote contém a reformulação visual mais recente, validada localmente em navegador desktop. Foram verificados:
- página inicial e menu;
- biblioteca de manuais;
- modal animado do Smart TAB;
- demonstração da página inicial;
- fluxo visual de desbloqueio.

O site publicado anteriormente em https://treinamento-smart-risk.luisquerdo.chatgpt.site pode estar em uma versão anterior a esta reformulação. Este ZIP é a fonte mais recente para continuar o desenvolvimento ou publicar em outro local.
